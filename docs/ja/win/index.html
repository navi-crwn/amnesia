02 · あなたの PC の毎日

これが毎日？

ブラウザは履歴と Cookie を保存します。ダウンロードとデスクトップには一度しか使わなかったファイルがたまっていきます。そして Windows も独自に記録を残します。最近使ったファイル、「ファイル名を指定して実行」やエクスプローラーで入力した内容、検索履歴、サムネイル、メモ帳のタブ、クリップボードの履歴です。

手作業で掃除するまでたまり続けます。あるいは、ずっとそのままです。

03 · Sign out

サインアウト。忘れました。

サインアウト、再起動、システム終了のどれかをすると、Amnesia がそれをすべて消去します。Windows が「サインアウトしてもいいですか？」と尋ねた瞬間に Amnesia は消去を始め、終わるまで Windows には「Amnesia is cleaning up...」と表示されます。残るのは選んだものだけです。Keep フォルダー、Keep List、そして保管庫のログイン情報です。インストール済みのプログラムもそのまま残ります。

次のサインイン時にもう一度確認するので、クラッシュや停電があっても痕跡は残りません。

Selective Amnesia はこのことを表す名前です。残すと決めたもの以外は、すべて忘れられます。

    04 · 残るもの

    消えるもの、残るもの。

    インストール直後の Amnesia は Off です。「I understand」にチェックを入れて Turn On を押すまで何も削除されません。リストを先に確認することもできます。

    サインアウト時に消去

    • ブラウザの履歴、Cookie、ログイン情報（Chrome、Edge など）
    • Desktop, Downloads, Documents, Pictures, Videos, Music
    • Windows の痕跡：最近使ったファイル、「ファイル名を指定して実行」とエクスプローラーの履歴、検索、サムネイル、メモ帳のタブ、クリップボードの履歴、ごみ箱
    • 保管庫にも Keep List にもないアプリのデータ

    安全に残る

    • Keep フォルダーの中身すべて（紫のアイコンが付き、デスクトップのショートカットとエクスプローラーのサイドバーにも表示されます）
    • Keep List のフォルダー（.ssh やコードエディターの設定など）
    • 保管庫に保存したログイン情報（Restore とパスワードで戻ります）
    • クラウドフォルダー：OneDrive、Dropbox、Google Drive、iCloud Drive、Nextcloud、MEGA、Box、pCloud、Proton Drive、そのほか Windows が同期フォルダーとして認識しているすべてのフォルダー
    • 仮想マシン（VirtualBox、Hyper-V、VMware、WSL、Docker、Android エミュレーター）と 1 GB 以上のディスクイメージ
    • Microsoft Store アプリのデータと、アプリが保存したパスワード（設定でオンにしない限り）
    • インストール済みのプログラム、ほかのドライブ、Windows のサインインに必要なもの

    05 · 実際の PC 向けに

    消すべきものは消し、消してはいけないものは残します。

    バージョン 0.8 は、全面的な監査と、実際の Windows 11 ノート PC でのテストから生まれました。サインアウトのたびに従うルールは次のとおりです。

    • Windows が尋ねた瞬間に消去します。 そのため、普通のサインアウトなら、サインイン画面が表示される前に消去が終わります。Windows がまだ開いているファイルは次のサインイン時に消え、セーフボックスは消去の後に閉じられます。
    • クラウドフォルダーは残ります。 移動すると同期アプリには「削除された」ように見え、クラウド上のファイルまで削除されるおそれがあります。クラウドにしかないファイルにも手を付けません。
    • 仮想マシンは残ります。 VM のディスクと 1 GB 以上のディスクイメージは残ります。この動作は、設定の Protection でオフにできます。
    • 新しいアプリは 3 日待ちます。 「Remove new apps」がオンの場合、新しいアプリのフォルダーはまず Amnesia のゴミ箱に入り、いきなり消えることはありません。Keep を押すと、そのプログラムとデータのフォルダーが Keep List に入ります。

    正直なトレードオフ：消去は Windows が尋ねた時点で始まるので、その後でサインアウトを取り消しても何も戻りません。「Clean now」を押したのと同じです。

    06 · Profile Vault

    パスワードひとつで、ログインが戻ります。

    アプリのログイン情報を入れておく暗号化された金庫です。Chrome、Edge、Brave、Firefox、Discord、Telegram、WhatsApp、Slack、Session、Element、Obsidian、Thunderbird、Bitwarden、VS Code、Claude、Antigravity、Windsurf、Gemini CLI、OpenCode、Git、そして追加した任意のフォルダーに対応しています。まっさらな PC にサインインしてパスワードをひとつ入力すれば、元に戻ります。

    • AES-256. スナップショットにはそれぞれ専用のランダムな鍵があり、その鍵は保管庫の鍵でロックされます。パスワードを忘れると、誰も開けません。
    • アプリを閉じるたびに保存。 変更があったときだけ、バックグラウンドで保存します。サインアウトは消去するだけなので、すぐに終わります。
    • 予備のスナップショット。 最新のものがおかしく見えたときのために、各アプリはひとつ前のスナップショットも残します。
    • アプリを見つけます。 まだ登録されていないインストール済みのアプリを提案します。パスワードの推測されにくさはメーターで表示されます。

    Memory Recall Restore で、パスワードを使ってログインを戻せます。サインインの後、通知でお知らせします。

    Global Amnesia パスワードを 3 回間違えるか、パニックワードを入力すると、保管庫は完全に削除されます。

    正直な注意点：Windows は保存されたログイン情報を Windows のユーザーに結び付けています。スナップショットが戻るのは、この PC のこのユーザーだけで、ほかの PC では戻りません。

    07 · 毎日

    Amnesia のある普通の一日。

    一度設定すれば、やることはこれだけです。

    1. 01

      Sign in

      PC はまっさらな状態で始まります。リマインダーをクリックし、保管庫のパスワードを入力して、Restore を押します。

    2. 02

      作業

      ログイン情報は戻っています。明日も必要なファイルは Keep フォルダーに入れてください。

    3. 03

      アプリを閉じる

      保管庫に入れたアプリは、閉じると個別に自動で保存されます。

    4. 04

      サインアウト

      ほかはすべて消去されます。痕跡は残りません。

    1 セッションの一時停止 Amnesia をオフにせずに、次のサインアウトとサインインを 1 回だけスキップします。

    08 · Backup

    バックアップと、新しい PC への移行。

    Keep フォルダー、Keep List、保管庫をロックされた 1 つのファイルにまとめます。保管庫でロックされるので、追加のパスワードは不要です。

    • USB ドライブ、別のドライブ、クラウドフォルダー（OneDrive、パソコン版 Google ドライブ）、SSH 経由の自分のサーバーに保存できます。毎日または毎週です。
    • バックアップは毎回、日付付きの新しいファイルになります。Amnesia が古いものを削除することはありません。
    • 使用中だったファイルは結果に表示されるので、何をもう一度バックアップすればいいかわかります。停電で途中で止まった復元は自動で後片付けをして、以前の保管庫を元に戻します。

    Memory Recall 新しい PC への移行：Amnesia をインストールし、バックアップを選んで、保管庫のパスワードを入力します。Keep フォルダー、Keep List、保管庫が戻ります。

    09 · すばやい退出

    急いで離れたい？ Amnesia が片付けます。

    詮索好きな人がいるとき、PC を借りているとき、誰かに「ちょっと開いて見せて」と迫られたときに。これらはすべて、設定でオンにするまでオフです。

    パニックホットキー

    Ctrl + Alt + Shift + X（または Q、F12）を押します。すぐに画面がロックされ、Amnesia はほかのアプリを待たずに消去してサインアウトします。一時停止中でも動作し、Windows の反応が遅い場合はもう一度試します。

    CtrlAltShiftX

    USB キー

    USB ドライブを選びます。抜くと Amnesia が消去してサインアウトするか、消去してシステム終了します。どちらにするかは選べます。

    放置したらサインアウト

    席を離れましたか？ 5〜60 分たつと 60 秒のカウントダウンが始まり、その後ロック、消去、サインアウトをします。マウスを動かすと止まります。

    パニックワード

    保管庫のパスワードを求められたら？ 代わりにパニックワードを入力します。保管庫はその場で削除され、そう設定していれば Keep フォルダーも削除されます。

    Doomsday

    保管庫のパスワードを続けて 3 回間違えると、保管庫は完全に削除されます。最後の 1 回の前に Amnesia が警告します。この機能はオフにできます。

    正直な注意書き：Amnesia が守るのはサインアウトした後です。サインイン中の PC はいつもどおり無防備なので、ロックしてください（Win+L）。すばやい退出は保存していない作業を待たず、パニックワードは取り消せません。

    10 · ロック

    正直にロックします。

    設定の Advanced に 2 つのロック、Keep List のページにセーフボックスがあります。できることと、できないことを説明します。

    Keep ロック

    Keep フォルダーは、専用のパスワードを使って Amnesia からしか開けません。Open Keep、トレイのメニュー、デスクトップのショートカットから開きます。画面をロックしたとき（Win+L）、設定した時間がたったとき、サインアウトとサインインのときに、またロックされます。ロック中は、どのプログラムも中のファイルを開いたり書き込んだりできません。

    • ファイルは暗号化されません。暗号化には BitLocker を使ってください。
    • ロック中もファイル名は見えたままです。
    • あなたとしてサインインした人が Windows に詳しければ、フォルダーのプロパティからロックを外せます。

    ラボロック

    コンピューター室や図書館など、多くの人が使う PC 向けです。管理者が 6 桁以上の PIN を設定します。それ以降、この Windows ユーザーは Amnesia をオフにすること、一時停止、終了、アンインストール、設定や Keep List の変更ができなくなります。Amnesia はサインインのたびに起動し、PIN を入力すると 10 分間設定を開けます。

    • タスクマネージャーで Amnesia を終了させることはできます。それでも次のサインイン時のチェックで消去されます。
    • 先に設定と Keep List を整えてください。その状態のままロックされます。

    セーフボックス 実験的

    Keep の中に作る、専用のパスワード付きのロックされたフォルダーで、特に大事なファイル用です。閉じているときは 1 つの暗号化ファイル（AES-256-GCM、保管庫と同じ形式）で、開くと Keep\Safe になります。Amnesia はサインアウトのたびに、消去の後でこれをまた閉じます。

    • 小さく保ってください。閉じるたびに中身をすべて詰め直すので、時間がかかります。
    • パスワードを忘れると、あなたも含めて誰も開けません。
    • 中にファイルが残っている間は、アンインストール時に警告されます。

    11 · ヘルスチェック

    ちゃんと動いている？ 見ればわかります。

    「Amnesia は今、きちんと仕事ができる？」に 1 ページで答えます。緑なら問題なし、黄と赤は確認すべきことを示し、各行に修正する場所が書かれています。

    • チェックする項目。 オンかオフか、Windows と一緒に起動するか、最後の消去、次のサインインに持ち越されたファイル、Windows セキュリティによるブロック、クラウドフォルダー、仮想マシン、Keep ロック、保管庫、最後のバックアップ、パニックホットキー、アップデート、ディスクの空き容量、メモリ、バッテリー。
    • スタートアップがオフになっていたら？ 誰かがタスクマネージャーで Amnesia をオフにした場合、ホームに「Switch it back on」ボタン付きの警告が表示されます。
    • 署名付きアップデート。 アップデートは、SHA256SUMS.txt の開発者の署名が確認できた場合にだけインストールされます。署名がなければ、Amnesia は何もインストールせず、リリースページを開きます。

    Amnesia にできないことを、アプリの中でも明記しています

    • 消去はファイルを削除するもので、ディスクを上書きするわけではありません。デバイスの暗号化をオンにしてください。
    • Windows はユーザーフォルダーの外にもいくつか痕跡を残します。
    • 保管庫とバックアップの強さは、パスワードの強さ次第です。
    • まだ有料のコード署名証明書がないので、SmartScreen が警告することがあります。

    12 · 消去されるもの

    まず確認。それから決める。

    「What gets wiped」は、次のサインアウトの予行演習です。消えることになるファイル、フォルダー、痕跡をすべて一覧にします。開くだけでは何も削除されません。

    • 検索。 「Downloads」や「.pdf」のように、名前やパスを入力します。
    • 1 つのフォルダー。 フォルダーを選ぶと、項目数とサイズがわかります。
    • Biggest first。 何が一番容量を使っているかがわかります。

    Review & sign out は、サインアウトの直前に同じリストと、削除されるプログラムを表示します。先に何かを残すためのボタンもあります。

    13 · プライバシー

    PC から何も出ていきません。

    Amnesia にはサーバーもアカウントもなく、トラッキングもアナリティクスもありません。アップデートの確認では、最新のバージョン番号を GitHub に問い合わせるだけです。

    サーバーなし アカウントなし トラッキングなし AES-256 インストールに管理者権限は不要 隠れた PowerShell なし パニックワード

    必要なときは、さらに。

    ここから下の機能はすべて設定にあります。追加機能は、オンにするまでオフです。

    Windows に記憶させない

    Windows 自身のプライバシー設定を、あなたのユーザーだけに適用します。最近使った項目の一覧なし、クリップボードの履歴なし、スタートでの Web 検索結果なし、広告 ID なし、Recall と Copilot はオフ。Undo all で、元の状態をそのまま戻せます。

    新しいアプリを削除

    Turn On の後にあなた専用にインストールされたプログラムは、Microsoft Store アプリも含め、サインアウト時に削除されます。そのフォルダーはまず Amnesia のゴミ箱で 3 日間待ちます。Keep を押すと、そのアプリのプログラムとデータのフォルダーが Keep List に入ります。

    アプリを残す

    一覧からインストール済みのアプリを選ぶと、Amnesia はそのアプリがデータを保存するフォルダーをすべて残します。ログイン情報や設定も含まれます。

    Store のデータと保存されたパスワード

    追加のスイッチが 2 つあります。Microsoft Store アプリのデータも消去するスイッチと、アプリが資格情報マネージャーに保存したパスワードも消去するスイッチです。Microsoft アカウント、OneDrive、Office は対象外です。

    残りかすを探す

    アンインストールしたプログラムが残したフォルダーやレジストリの設定です。チェックを入れるまで何も消えません。

    使い捨ての Windows

    怪しいファイルや Web サイト用に Windows サンドボックスを開きます。閉じると消えます。Windows Pro または Enterprise が必要です。

    Windows の保護

    PC 全体に対して（管理者権限、確認は一度だけ）：システム終了時にページファイルを空にする、休止状態をオフ、Recall とアクティビティの履歴をオフ。

    署名付きアップデート

    アップデートの確認では、リリースの開発者の署名を読み取ります。有効な署名がなければインストールせず、代わりにリリースページを開きます。

    追加の消去リスト

    コミュニティのリスト Winapp2（約 4,000 アプリ）で、ボタンを押したときに GitHub からダウンロードします。保存されたパスワードには一切触れません。

    ウイルス対策ソフトと共存

    消去は Amnesia.exe の中で実行されます。Windows セキュリティに何かをブロックされた場合は、Amnesia を許可する方法をホームで案内します。「ウイルス対策をオフにして」とは決して言いません。

    履歴

    PC がいつ消去されたか、どのアプリが保存されたか、いつバックアップが実行されたか。ファイル名は残しません。

    ログの収集

    うまく動かないときは、Keep フォルダーにテキストファイルを 1 つ作ります。ファイル名は含みません。何も送信されません。何を共有するかはあなたが決めます。

    ディスク暗号化のチェック

    BitLocker またはデバイスの暗号化がオンかどうかと、オンにする方法を設定に表示します。

    空き領域の消去

    Windows 標準の cipher /w を実行し、削除したファイルを復元しにくくします。時間がかかり、実行前に確認があります。

    メンテナンス。まずリストを見てから、空きを増やす。

    Amnesia はサインアウトのたびにユーザーフォルダーのほとんどをもう消しています。だからメンテナンスは残るもののためにあります。Keep フォルダー、残したアプリ、このセッションでできた大きなファイルです。どの操作も先にスキャンしてリストを見せ、危ないものにはチェックを入れません。

    ディスクの概要

    何が容量を使っているかを表示します。Keep フォルダー、保管庫、ごみ箱、Temp、いちばん大きいフォルダーとファイル、古いダウンロード。見るだけで、ここでは何も消しません。

    今すぐ消去

    Temp、クラッシュダンプ、アプリのキャッシュ、Amnesia のゴミ箱を空にします。Windows がまだ開いているファイルは飛ばします。ごみ箱もリストにありますが、チェックは入れません。

    アプリを削除

    自分専用に入れたプログラムは、そのプログラム自身のアンインストーラーを実行します。全員向けのプログラムは Windows の設定を開きます。残ったキャッシュはごみ箱へ。個人データは、チェックを入れない限り残ります。

    プロジェクトのビルドフォルダー

    node_modules、target、build、dist、それに .NET プロジェクトの bin と obj をごみ箱に移せます。この 7 日間に使ったフォルダーや git で管理されているものには触れません。

    古いインストーラー

    古い .msi と .msix はごみ箱へ。setup の .exe はリストに出ますが勝手には選ばず、ディスクイメージや仮想マシンも同じです。

    安全なお手入れ

    エクスプローラーを再起動するか、スタートアップ アプリやストレージの設定を開きます。管理者は不要です。

    迷ったら止まる

    Keep List が読めないか見つからないときは、消去は何も消さずに止まり、そのことを履歴に残します。確認できないときは、その項目を残します。

    毎回履歴に残る

    メンテナンスのたびに、空いた容量と一緒に履歴に残ります。ヘルスチェックにはディスクの空き容量、メモリ、バッテリーも出ます。

    モードとプロファイル。どれだけ忘れるかは、あなたが決める。

    サインアウトごとのモードを1つ選び、必要なアプリだけを復元し、ファイルを共有せずにAIに相談できます。どの変更もまずプレビューが表示され、次のサインアウトから有効になります。

    Retrograde Amnesia

    サインインのたびに新品のアカウントのよう。残るのはKeepフォルダとAmnesiaの動作に必要なものだけ。サインアウト時の保管庫の自動スナップショットはオフになりますが、スナップショットは手動で復元できます。

    Selective Amnesia (おすすめ)

    Keepフォルダは残り、アプリのログインは保管庫から戻ります。これまでと同じです。

    Partial Amnesia

    AppDataの中身はすべて残るので、アプリは設定とログイン、そしてキャッシュも保ちます。あなたのファイル、ダウンロード、デスクトップは消去されます。ブラウザ自身のフォルダ内の閲覧履歴とCookieも残ります。そのフォルダが保持されるためです。

    Custom Amnesia

    あなた自身のKeep List。モードが追加した行を変更すると自動で選ばれます。モードは自分のマーク付きセクションだけを変更するので、あなた自身の行は常に残ります。

    切り替えの前に必ずプレビュー

    これから消去されるものと、これから残るものを確認でき、消去が増えるときは警告が出ます。切り替えた時点では何も削除されません。モードのリストが見つからない・壊れている場合でも、Keep Listが空になることはありません。

    保管庫のプロファイル

    仕事用やプライベート用など、必要なものだけ、またはすべてを復元できます。プロファイルの名前変更、追加、削除も可能。1つのブラウザは1組のログインを持つので、2つ目のブラウザを使えば個人用を分けておけます。

    AIに相談

    Amnesiaはファイルの中身もファイル名も含まないレポートと、すぐ使えるプロンプトを作ります。好きなAIに貼り付け、回答を貼り戻して、必要な変更にチェックを入れるだけ。Amnesia自身は何も送信しません。

        よくある質問にお答えします。

        安全性

        何も削除せずに試せますか？

        はい。インストール直後の Amnesia は Off で、何も削除しません。What gets wiped を開いて Show preview を押してください。消えることになるものを一覧にするだけです。リストに問題がなければオンにしてください。

        消去されたファイルはどこへ行きますか？ 取り戻せますか？

        あなたが取り出せる場所には残りません。ごみ箱には移動せず、取り戻すことはできません。Amnesia をオンにすると本当に削除するので、先に What gets wiped を確認し、必要なものは Keep か Keep List に入れてください。

        Keep フォルダーは暗号化されますか？

        いいえ。Amnesia は残すだけで、暗号化はしません。BitLocker またはデバイスの暗号化をオンにしてください：設定 → プライバシーとセキュリティ → デバイスの暗号化。オンになっているかどうかは、Amnesia の設定に表示されます。

        PC がクラッシュしたり、電源が切れたりしたら？

        次のサインイン時のチェックで対処し、消去を行います。

        サインアウトを取り消したらどうなりますか？

        Amnesia は、Windows が「サインアウトしてもいいですか？」と尋ねた瞬間に消去します。その後で取り消した場合（たとえば、アプリが保存を求めてきたとき）でも、消去はすでに実行されています。「Clean now」を押したのと同じです。迷ったときは Review & sign out を使ってください。

        OneDrive、Dropbox、仮想マシンは消去されますか？

        いいえ。クラウドフォルダー（OneDrive、Dropbox、Google Drive、iCloud Drive、Nextcloud、MEGA、Box、pCloud、Proton Drive、そして Windows のあらゆる同期フォルダー）には手を付けません。移動するとクラウド上のファイルまで削除されるおそれがあるからです。VM のディスクと 1 GB 以上のディスクイメージも、設定の Protection でオフにしない限り残ります。

        ちゃんと動いているか、どうすればわかりますか？

        ホームページでヘルスチェックを開きます。各行が緑、黄、赤で表示され、修正する場所が書かれています。履歴には、すべての消去と、消えた項目の数が表示されます。

        データはどこかに送信されますか？

        いいえ。サーバーもアカウントもトラッキングもありません。バックアップは選んだ場所にだけ送られます。アップデートの確認では、最新のバージョン番号を GitHub に問い合わせ（標準では毎週）、これはオフにもできます。

        Windows セキュリティやウイルス対策ソフトにブロックされます。どうすればいいですか？

        何かが拒否されると、ホームで知らせます。たいていは「コントロールされたフォルダー アクセス」が原因です：Windows セキュリティ → ウイルスと脅威の防止 → ランサムウェア防止 → アプリをコントロールされたフォルダー アクセスで許可、と進み、Amnesia を追加してください。ウイルス対策ソフトはオフにしないでください。

        ロックとすばやい退出

        Keep ロックは回避できますか？

        はい。あなたとしてサインインした人が Windows に詳しければ、フォルダーのプロパティからロックを外せます。ファイルも暗号化されていません。ちょっとしたのぞき見やほかのプログラムは防げますが、本気の相手は防げません。しっかり守るには BitLocker を使ってください。

        Keep ロックのパスワードを忘れました。

        Keep フォルダーのプロパティ → セキュリティを開き、「拒否」の行を削除してください。ファイルはそのまま残っています。

        パニックホットキーを押すとどうなりますか？

        すぐに画面がロックされ、Amnesia はほかのアプリを待たずに消去してサインアウトします。保存していない作業は失われます。トレイのメニューにも同じ機能があります：Panic sign out now。

        セーフボックスとは？

        Keep の中に作る実験的なロックされたフォルダーで、特に大事なファイル用です。閉じているときは 1 つの暗号化ファイル（AES-256-GCM、保管庫と同じ）で、開くと Keep\Safe になります。Amnesia はサインアウトのたびに、消去の後でこれをまた閉じます。小さく保ってください。閉じるたびに中身をすべて詰め直します。

        ラボロックは止められますか？

        タスクマネージャーで Amnesia を終了させることはできます。それでも次のサインイン時のチェックで消去されます。設定の変更やオフにするには、管理者の PIN が必要です。

        Profile Vault

        保管庫のパスワードを忘れたら？

        その場合、あなたも含めて誰も開けません。新しい保管庫を作って、もう一度各アプリにサインインしてください。パスワードは安全な場所に書き留めておきましょう。

        保管庫はいつ保存されますか？

        変更のあったアプリを閉じた後に、バックグラウンドで保存します（1 分ごとに確認）。Claude Code や Git のようにウインドウのないツールは、変更がなくなってから 3 分後です。Edge がバックグラウンドで動き続けている場合（「スタートアップ ブースト」）は、本当に終了したときに保存されます。

        ログイン情報はほかの PC でも使えますか？

        通常は使えません。Windows は保存されたログイン情報を Windows のユーザーに結び付けているので、スナップショットが戻るのはこの PC のこのユーザーだけです。新しい PC への移行で Keep フォルダー、Keep List、保管庫は戻りますが、一部のアプリにはもう一度サインインが必要になることがあります。

        最新のスナップショットがおかしいです。

        新しいスナップショットが前回よりかなり小さい場合は、保管庫がそう知らせます。復元するときに「Use the snapshot before the newest one」にチェックを入れてください。

        パニックワードと Doomsday とは？

        パニックワードは、あなたが決める任意の言葉です。パスワード欄に入力すると、保管庫を削除します（そう設定していれば Keep フォルダーも）。Doomsday は、パスワードを続けて 3 回間違えると保管庫を削除します。Doomsday はオフにできます。

        インストールとアップデート

        インストール時に Windows が警告するのはなぜですか？

        アプリにまだ署名がないので、Windows はこのアプリを知りません。More info（詳細情報）を押してから、Run anyway（実行）を押してください。確かめたい場合は、同じリリースの SHA256SUMS.txt とファイルを照合してください。

        x64 と arm64 のどちら？

        ほとんどの PC は x64 です。Snapdragon 搭載のノート PC や、Mac 上の Windows 仮想マシンなど、Windows on ARM の場合は arm64 を選んでください。

        管理者権限は必要ですか？

        いいえ。あなた専用にインストールされます。Windows に管理者権限を一度だけ求めるのは、いくつかの任意の機能だけです：Windows の保護、残ったフォルダーの削除、ラボロック。

        アップデートするには？

        設定 → Update → Check now。アップデートをインストールする前に Amnesia をオフにし、その後またオンにしてください。Amnesia がアップデートをインストールするのは、開発者の署名が確認できた場合だけで、そうでなければリリースページを開きます。

        アンインストールするには？

        設定 → Uninstall Amnesia、またはほかのアプリと同じように「アプリと機能」から。まずオフになるので、それ以上は何も消去されません。Keep フォルダーは常に残ります。Keep がロックされている場合は Keep のパスワードを求め、セーフボックスにまだファイルがあれば警告します。設定、Keep List、保管庫も削除するには、ボックスに DELETE と入力してください。

        Microsoft Store アプリや新しいプログラムは削除されますか？

        「Remove new apps」がオンの場合だけです。その場合、Turn On の後にあなた専用にインストールされたプログラムはサインアウト時に削除され、そのフォルダーはまず Amnesia のゴミ箱で 3 日間待ちます。残すには Keep を押してください。Store アプリのデータは、「Also wipe Store app data」をオンにしない限りそのまま残ります。

        Mac 版はありますか？

        はい、しかも Mac 版のほうが歴史は長いです。Mac のページをご覧ください。

        バグを見つけましたか？ 変えてほしいことがありますか？

        GitHub で Issue を立ててください。パスワード、非公開のファイル一覧、個人的な情報は貼り付けないでください。そのため、ログの収集ではファイル名を含めません。

        Issue を立てる

        ダウンロードしたら、あとは全部忘れてください。名前どおりです。

        バグを見つけたか、アイデアがありますか？ Issue を立ててください。パスワードや非公開のファイル一覧は含めないでください。
