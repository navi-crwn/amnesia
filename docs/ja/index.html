02 · あなたの Mac の毎日

これが毎日？

Mac は毎日、あなたが何をしたかを黙って記録しています。ブラウザは履歴と Cookie を保存します。ダウンロード、デスクトップ、書類には一度しか使わなかったファイルがたまっていきます。アプリはキャッシュやログを書き込み、ターミナルは入力したコマンドをすべて覚えています。

手作業で掃除するまで、毎日たまり続けます。あるいは、ずっとそのままです。

03 · ログアウト

ログアウト。忘れました。

Log Out、再起動、システム終了のどれかを押すと、Amnesia がそれをすべて消去します。残るのは選んだものだけです。Keep フォルダー、Keep List のアプリ、そして Profile Vault に保存したログイン情報です。インストール済みのアプリもそのまま残ります。

次のログイン時にもう一度確認するので、クラッシュや停電があっても痕跡は残りません。

Selective Amnesia はこのことを表す名前です。残すと決めたもの以外は、すべて忘れられます。

    04 · 残るもの

    消えるもの、残るもの。

    Turn On を押すまで何も削除されません。リストはいつでも先に確認できます。検索したり、大きいファイルを上に並べたりできます。

    ログアウト時に消去

    • ブラウザの履歴と Cookie
    • Desktop, Downloads, Documents, Pictures, Movies, Music
    • キャッシュ、ログ、ターミナルの履歴
    • ゴミ箱の中身すべて
    • 保管庫にも Keep List にもないアプリのデータ

    安全に残る

    • Keep フォルダーの中身すべて（場所も名前も自由）
    • Profile Vault に保存したログイン情報（Restore で戻ります）
    • Keep List のアプリ（VPN、SSH キー、Apple アカウント…）
    • 仮想マシン（UTM、Parallels、VirtualBox、VMware Fusion）。標準で残ります
    • インストール済みのアプリ本体

    05 · Profile Vault

    パスワードひとつで、すべてのログインが戻ります。

    アプリのログイン情報を入れておく暗号化された金庫です。これがあるので、まっさらな Mac にログインしても、Chrome、WhatsApp、Claude、コーディングツールをワンステップで使える状態に戻せます。

    • AES-256. 7-Zip でロックされます。パスワードを忘れると、誰も開けません。
    • 軽量スナップショット。 ブラウザをキャッシュなしで保存します。約 1 GB が 150 MB になります。
    • Save & Log Out。 ワンクリックでログイン情報を保存してからログアウトします。保存に失敗した場合、ログアウトは中止されます。
    • Undo Restore。 Mac 上のデータがスナップショットより新しい場合は、先に確認されます。Keep List にあるものは上書きされません。また、次にログアウトするまでは、ボタンひとつで元の状態に戻せます。

    Memory Recall Restore Profiles を押すと、消去されたログアウトの後でもすべてのログインが戻ります。

    Global Amnesia パスワードを 3 回間違えるか、パニックワードを入力すると、保管庫は完全に削除されます。

    3. 03

    4. 04

    07 · Backup

    バックアップはどこにでも。

    Keep フォルダー、選んだフォルダー、Profile Vault を暗号化した .7z コピー（AES-256、ファイル名も暗号化）です。

    • USB ドライブ、SSH 経由の自分のサーバー、Google Drive、Dropbox、OneDrive、Box、pCloud に保存できます。毎日または毎週で、バックアップファイルの確認もできます。
    • バックアップは毎回、日付付きの新しいファイルになります。Amnesia が古いバックアップを削除することはありません。

    Memory Recall Restore Files でファイルを元の場所に戻せます。Get Vault from Backup で失くした保管庫を取り戻せます。

    08 · プライバシー

    Mac から何も出ていきません。

    Amnesia にはサーバーもアカウントもなく、トラッキングもアナリティクスもありません。すべて Mac の中で動きます。

    サーバーなし アカウントなし トラッキングなし AES-256 sudo は一切使いません ファイル名を残さない履歴 パニックワード

    わかる人にはわかる 😉

    説明したくない人のために。

    Mac を貸すとき？

    ログアウトして、もう一度ログインして、渡すだけ。ブラウザの履歴、ログイン情報、最近使ったファイル、チャットはもう消えています。保管庫はロックされたままです。

    詮索好きな家族？

    ブラウザの履歴はログアウトすると残りません。深夜 3 時の爆買いは、誰にも知られなくて大丈夫です。

    「ちょっと開いて見せてよ」

    ログインすると、空っぽのデスクトップが表示されます。保管庫のパスワードも求められたら？ 代わりにパニックワードを入力します。保管庫は消え、そう設定していれば Keep フォルダーも消えます。騒ぐ必要はありません。

    紛失や盗難のときは？

    ログアウトした後なら、履歴、ログイン情報、チャットはもう消えていて、保管庫は AES-256 で暗号化されています。FileVault もオンにしておけば、Keep フォルダーもディスク上で暗号化されます。

    $ amnesia --forget-everything # 名前どおりです

    正直な注意書き：Amnesia が守るのはログアウトした後です。ログイン中の Mac はいつもどおり無防備なので、画面をロックしてください。また、パニックワードは取り消せません。

    毎日きれいに。失うものはなし。

    Amnesia でできることを一覧にしました。下にスクロールするとアプリをボタンごとに分解して紹介し、その後チュートリアルに進みます。

    自動消去

    ログアウト、再起動、システム終了時に実行し、ログイン時にもう一度確認します。

    Profile Vault

    Chrome、WhatsApp、Claude、コーディングツールを AES-256 でロックします。パスワードひとつで元に戻せます。

    ブラウザの軽量スナップショット

    Chrome、Brave、Edge、Arc、Vivaldi、Opera はキャッシュなしで保存できます。約 1 GB が 150 MB になります。ブラウザごとにスイッチひとつで切り替えられます。

    Save & Log Out

    ワンクリックでログイン情報を保存してからログアウトします。保存に失敗した場合、ログアウトは中止されます。

    自動スナップショット

    Save & Log Out を忘れても大丈夫。普通にログアウトしても、変更のあったアプリを先に保存します。

    残すものを選ぶ

    ファイル用の Keep フォルダーと、VPN や SSH キーなどのアプリ用の Keep List があります。仮想マシンは最初から Keep List に入っています。

    先に確認

    「What Gets Deleted」では、何かを削除する前にすべてを一覧表示します。検索や Biggest first での並べ替えもできます。1 GB 以上のファイルには警告が付きます。ログアウトをあなたの OK まで待たせることもできます。

    Pause 1 Session

    Amnesia をオフにせずに、次のログアウトとログインを 1 回だけスキップします。

    どこにでもバックアップ

    USB ドライブ、SSH 経由の自分のサーバー、Google Drive、Dropbox、OneDrive、Box、pCloud に保存できます。毎日または毎週で、バックアップファイルの確認もできます。

    履歴

    Mac がいつ消去されたか、どのアプリが保存されたか、いつバックアップが実行されたか。ファイル名は残しません。

    パニックワード

    これを入力するか、パスワードを 3 回間違えると、保管庫は完全に削除されます。

    新しい Mac への移行

    保管庫とキーチェーンのキーを持っていけるので、新しい Mac でもアプリがログインした状態で開きます。

    開発者ツール

    SSH、GitHub CLI、シェル、エディター、Docker、クラウド、AI CLI の設定を残せます。Pick Apps には、この Mac にあるものだけが表示されます。

    どの設定もすぐ見つかる

    設定画面の上にある検索ボックスに、英語またはインドネシア語で入力します。ウインドウのサイズも変えられます。

    Keep ロック

    Amnesia で Keep のパスワードを入力するまで、Finder やほかのアプリは Keep フォルダーを開けません。しばらくすると自動でまたロックされます。暗号化ではなく macOS のアクセス権を使うので、Keep の直下にあるファイルの名前は見えたままです。

    ヘルスチェック

    対応が必要なことを 1 ページで知らせます。フルディスクアクセス、iCloud のデスクトップと書類、シンボリックリンクのフォルダー、仮想マシン、大きなファイル、最後のバックアップ、FileVault。ほとんどの項目に修正ボタンがあります。

    Brankas （実験的）

    Keep フォルダーの中に作る暗号化ディスク（AES-256）で、絶対に秘密にしたいファイル用です。Amnesia は毎回の消去の前にこれを閉じ、閉じられなかったときは知らせます。パスワードを忘れると、ファイルは失われます。

    署名付きアップデート

    アプリ内からのアップデートは、リリースの SHA256SUMS.txt に有効な署名がある場合にだけインストールされます。署名がなければ、代わりにリリースページが開きます。

    iCloud でも安全

    iCloud の「デスクトップと書類」がオンの場合、この 2 つのフォルダーはスキップされるので、iCloud やほかのデバイスから何かが削除されることはありません。シンボリックリンクのフォルダーは、リンク越しに中身が消されることはありません。

    Claude と Claude Code

    Claude を Keep List に入れると、Claude Code のチャット（~/.claude）も残ります。ログアウトの前には、保管庫でチェックを入れたアプリの新しいスナップショットを取るので、復元したデータが古いということはありません。

      01 / 10

      Amnesia を開いて警告を読む

      Amnesia を初めて開くと、短いツアーが始まります。言語を選び、Amnesia が何を削除するかを読んで、理解したことにチェックを入れます。この時点ではまだ何も削除されません。

      • ツアーはあとで設定からもう一度開けます。

      02 / 10

      クイックチェック

      Amnesia は、必要なもの（エンジン、7-Zip、Apple Command Line Tools、フルディスクアクセス）をチェックします。緑になっていない項目には、横にボタンがあります。

      • フルディスクアクセス：「システム設定」→「プライバシーとセキュリティ」→「フルディスクアクセス」→ Amnesia をオンにしてから、Quit & Reopen を押します。
      • あとで「設定」→「ヘルスチェック」を開くと、同じ内容に加えて、iCloud のデスクトップと書類や最後のバックアップなども確認できます。
      • これで、消去がデスクトップ、書類、ダウンロードまで届くようになります。

      03 / 10

      残すものを選ぶ

      Keep フォルダー（標準は ~/Keep）を選び、データを消去したくないアプリをオンにします。VPN アプリはおすすめとして表示され、Apple アカウントには最初からチェックが入っています。

      • これはあとで Keep List のページで変更できます。
      • この Mac でコードを書きますか？ Keep List → Pick Apps → Developer tools & terminal で、SSH、Git、CLI の設定を残せます。
      • Claude を使っていますか？ Pick Apps → Claude → Save で、Claude Code のチャットも残せます。

      04 / 10

      Profile Vault を作成する

      Profile Vault を開き、12 文字以上のパスワードを 2 回入力します。パニックワードは任意です。

      • パスワードは安全な場所に書き留めてください。誰にも復元できません。
      • Global Amnesia パニックワードを入力すると、保管庫は完全に削除されます。

      05 / 10

      アプリを選んで、最初のスナップショットを取る

      保存するアプリをクリックし、ブラウザごとに Light か Full を選び、いつもどおりそのアプリにログインしてから、Snapshot Now を押します。

      • Snapshot Now にパスワードは不要です。
      • Light はキャッシュを省きます。約 1 GB が 150 MB になります。

      06 / 10

      保管庫ごとバックアップする

      バックアップ先を選び、Include Profile Vault にチェックを入れたまま Back Up Now を押します。その後、Check a Backup File で中の保管庫が開けることを確かめてください。

      • Memory Recall もし保管庫を失くしても、Get Vault from Backup で取り戻せます。
      • バックアップは毎回、日付付きの新しいファイルになります。古いものは削除されません。

      07 / 10

      リストを見る

      What Gets Deleted には、次のログアウトで削除されるものがすべて、種類ごとにまとめて表示されます。まだ必要なものがありますか？ Keep フォルダーに移すか、そのアプリを Keep List に追加してください。

      • リストを開くだけでは何も削除されません。
      • Biggest first にチェックを入れて、1 GB 以上のファイルについてのオレンジ色の警告を確認してください。
      • 「Remove apps installed later」がオンの場合、それらのアプリもここの「Apps installed later」に表示されます。

      08 / 10

      Turn On

      ホームのカードで Turn On Amnesia を押し、ポップアップを読みます。このセッションは、ログアウトするまで安全です。

      • Selective Amnesia これからは、ログアウト、再起動、システム終了のたびに、選んだもの以外はすべて忘れられます。

      09 / 10

      毎日：Save & Log Out、そして Restore

      今日の作業は終わりですか？ メニューバーで Save & Log Out を押します。もう一度ログインしたら、Profile Vault を開いてパスワードを入力し、Restore Profiles を押します。

      • Memory Recall Chrome、Claude、WhatsApp などが、ログインした状態で戻ります。
      • Light で保存した場合は、ブラウザの拡張機能ページで「修復」を押してください。

      10 / 10

      Amnesia のアップデート

      必ずこの順番で：Turn Off、アップデートをインストール（.dmg または brew upgrade）、Amnesia を開く、Turn On。

      • Amnesia がオンのままインストールすると、ログアウトとして扱われ、セッションが消去されることがあります。
      • アプリ内からアップデートする場合は、有効な署名のあるリリースだけがインストールされます。

        12 · FAQ

        よくある質問にお答えします。

        安全性

        データはどこかに送信されますか？

        いいえ。Amnesia にはサーバーもアカウントもなく、トラッキングもアナリティクスもありません。すべて Mac の中で動きます。Mac から出ていくのは、サーバーやクラウドへのバックアップを設定した場合のロックされた .7z ファイルだけで、選んだ保存先にそのまま送られ、パスワードがなければ誰も読めません。アップデートの確認では、最新のバージョン番号を GitHub に問い合わせるだけで、標準では週に 1 回です。設定で 2 週間ごと、毎月、オフにも変えられます。

        Windows 版はありますか？

        はい。正式リリースの Amnesia for Windows v0.8.1 があります。サインアウト、再起動、システム終了時に消去し、保管庫、バックアップ、Keep ロック、セーフボックス、ヘルスチェック、アプリ内からの署名付きアップデートに対応した Setup.exe があります。Windows のページをご覧ください。

        何も削除せずに試せますか？

        はい。Turn On を押すまで、Amnesia はオフのままです。What Gets Deleted（または「設定」→「See what would be deleted now」）で、先に完全なリストを確認できます。

        消去されたファイルはどこへ行きますか？ 取り戻せますか？

        ログアウト時に Amnesia 専用のフォルダー（~/.amnesia-trash）に移され、次のログイン後にバックグラウンドで空にされます。macOS のゴミ箱には入らず、取り戻すことはできません。必要なものは Keep フォルダー、Keep List、保管庫に入れておいてください。

        Keep フォルダーは暗号化されますか？

        Amnesia では暗号化しません。Keep ロックは、Keep のパスワードを入力するまで Finder やほかのアプリが開けないようにしますが、これは macOS のアクセス権で、暗号化ではありません。ディスク全体を暗号化するには FileVault をオンにし、絶対に秘密にしたいファイルは Brankas に入れてください。

        Mac がクラッシュしたり、電源が切れたりしたら？

        ログイン時のチェックで対処します。前回のログアウトが完了していなければ、ログイン時のチェックで消去をすべて行います。

        なぜフルディスクアクセスが必要なのですか？

        macOS がフォルダー（デスクトップ、書類、ダウンロード…）ごとに確認を求めないようにするためと、ログアウト時の消去が実際にそれらに届くようにするためです。許可は一度だけで済みます。

        iCloud のデスクトップと書類を使っています。問題はありますか？

        その場合、Amnesia はデスクトップと書類をスキップします。消去すると iCloud とほかのデバイスからもファイルが削除されてしまうからです。ヘルスチェックと What Gets Deleted で知らせます。これらも消去したい場合は、先にその iCloud のオプションをオフにしてください。

        Mac のパスワードや sudo は必要ですか？

        いいえ。Amnesia は自分のユーザーアカウントの中だけで動き、sudo は一切使いません。macOS がログインパスワードを求めるのは、新しい Mac への移行のためにキーチェーンのキーを保存するときだけです。

        Backup

        バックアップの設定にターミナルや Chrome は必要ですか？

        いいえ。サーバーの場合は、そのパスワードを一度入力すれば Amnesia が SSH キーをインストールします。Google Drive、Dropbox、OneDrive、Box、pCloud の場合は、ブラウザでログインします。

        バックアップが本当に使えるか、どうすればわかりますか？

        バックアップのページで Check a Backup File を押し、.7z を選びます。Amnesia は中の保管庫を一時フォルダーで開いて、入っているアプリを表示し、その一時フォルダーを削除します。あなたの保管庫には触れません。

        見ていない間も、スケジュールしたバックアップは動きますか？

        はい。Amnesia のアイコンがメニューバーにあり、パスワードがキーチェーンに保存されていれば動きます。USB ドライブの場合は、ドライブが接続されるまで待ちます。毎回通知が届きます。「Run the scheduled backup now」ですぐにテストできます。

        バックアップからファイルを戻すには？

        バックアップ → Restore Files：.7z を選び、フォルダーやファイルにチェックを入れて、Restore to Original Place を押します。Amnesia は各フォルダーが元々どこにあったか（外付けドライブ上でも）を覚えています。すでにそこにあるものは先に ~/.amnesia/before-restore に移されるので、何も上書きされません。ドライブが接続されていない場合は、To Another Folder を使ってください。

        バックアップをダブルクリックで開けないのはなぜですか？

        バックアップは AES-256 でロックされていて、ファイル名の一覧まで暗号化されています。Mac に標準で入っている「アーカイブユーティリティ」ではこれを開けません。Amnesia の Restore Files、無料アプリの Keka、またはターミナルを使ってください：~/.amnesia/bin/7zz x file.7z（パスワードは聞かれたときに入力し、コマンドには含めないでください）。

        Check a Backup File で、バックアップに保管庫がないと表示されます。壊れていますか？

        いいえ。Include Profile Vault をオフにして（または v5.13 より前に）作ったバックアップです。中のファイルは問題ありません。パスワードが間違っている場合は、別のメッセージでそう表示されます。

        スケジュールしたバックアップで Mac のパスワードを求められました。なぜですか？

        以前のバージョンの Amnesia がバックアップのパスワードをキーチェーンに保存していた場合、macOS が一度だけ確認します。Always Allow を押してください。v5.17 からは Amnesia が自分のものとして保存し直すので、もう聞かれません。

        古いバックアップは削除されますか？

        いいえ、決して。バックアップは毎回、日付付きの新しいファイルになります。不要になった古いものは、ご自身で削除してください。

        Profile Vault

        保管庫のパスワードを忘れたら？

        その場合、あなたも含めて誰も開けません。新しい保管庫を作って、もう一度各アプリにログインしてください。パスワードを覚えていて、新しいものに変えたい場合は、Profile Vault のページの Password ボタンを使ってください。

        パスワードを 3 回間違えるとどうなりますか？

        保管庫は完全に削除されます。最後の 1 回の前に Amnesia が警告します。保管庫がバックアップに入っていれば、Move to a New Mac → Get Vault from Backup で取り戻せます。

        Light と Full の違いは？

        Light（ブラウザのみ）は、キャッシュと Web ストアの拡張機能のプログラムファイルを除くので、Chrome は約 1 GB から 150 MB になります。ログイン情報、ブックマーク、拡張機能の設定、ほかの方法でインストールした拡張機能は常に保存されます。Light で Restore した後は、ブラウザの拡張機能ページで「修復」を押してください。Full はキャッシュ以外のすべてを保存します。

        Save & Log Out で古いスナップショットは上書きされますか？

        上書きされるのは保存するアプリの分だけで、新しいスナップショットの保存に成功した後だけです。リストにないアプリは、そのスナップショットがそのまま残ります。保存に失敗した場合は、ログアウトしません。

        自動スナップショットは何をしますか？

        普通の方法でログアウト、再起動、システム終了をすると、Amnesia はまずデータが変わったアプリを保存し（最大 150 秒）、それから消去します。直前に Save & Log Out を使った場合や、Pause 1 Session がオンの場合はスキップされます。オフにすると、普通のログアウトでは保存せずに消去します。

        復元したら、新しいデータが古い状態に戻ってしまいました。元に戻せますか？

        はい、次にログアウトするまでなら戻せます。Profile Vault のページで Undo Restore を押すと、復元する直前のデータが戻ります。v5.23 からは、アプリのデータがスナップショットより新しい場合に Amnesia が先に確認し、Keep List にあるものは上書きしません。

        パニックワードとは？

        あなたが決める任意の言葉です。パスワード欄に入力すると、すぐに保管庫を削除します（そう設定していれば、Keep フォルダーも空にします）。

        毎日の使い方

        明日もファイルが必要です。どうすればいいですか？

        ログアウトする前に Keep フォルダーに移してください。1 日だけなら、Pause 1 Session を押します。次のログアウトとログインでは消去されません。

        ログアウトを取り消せますか？

        はい。「Check before logout」（設定）をオンにすると、ログアウト、再起動、システム終了は、Continue か Cancel を押すまで What Gets Deleted のページで待ちます。

        ログイン時にメインウインドウが開きます。なぜですか？

        以前のバージョンでは、macOS の「再ログイン時にウインドウを再度開く」によって開き直されていました。v5.15 からは、ログイン時に Amnesia はメニューバーのアイコンだけを表示します。

        仮想マシンを使っています。消去されますか？

        標準では消去されません。Amnesia が UTM、Parallels、VirtualBox、VMware Fusion のデータを見つけると、一度だけ Keep List に追加します。オフにすればオフのままになり、その行にはログアウト時に消去されると表示されます。What Gets Deleted でも、1 GB 以上のファイルについて警告します。

        ゴミ箱も空にされますか？

        はい、ログアウトのたびに空にされます。What Gets Deleted では「Trash (emptied at logout)」という専用のグループとして、サイズと一緒に表示されます。まだ必要なものは、先に取り出しておいてください。

        アップデートするには？

        Turn Off を押し、新しいバージョンをインストール（.dmg または brew upgrade）して、Amnesia を開き、Turn On を押します。

        アプリ内からのアップデートは安全ですか？

        リリースの SHA256SUMS.txt に、Amnesia に組み込まれた開発者の鍵による有効な署名がある場合にだけインストールされます。署名がないか正しくない場合は、代わりにリリースページを開き、何もインストールしません。

        新しい Mac に移行できますか？

        はい。Move to a New Mac のページで手順を案内します。Prepare Move でキーチェーンのキーを保管庫に保存し、バックアップでそれを移し、Restore Keys で新しい Mac に戻します。

        Uninstall

        アンインストールするには？

        設定を開き、Uninstall Amnesia を押します。Amnesia は完全にオフになり、アプリはゴミ箱に移動します。チェックボックスで、保管庫、スナップショット、Keep List、設定も削除できます（これらもゴミ箱に移動します）。Keep フォルダーには一切触れません。ターミナルを使う場合は bash ~/.amnesia/uninstall.sh（保管庫も削除するには --all を付けます）。Homebrew の場合は brew uninstall amnesia です。

        Keep ロックがオンです。アンインストールするとどうなりますか？

        Amnesia が Keep のパスワードを求め、先に Keep のロックを解除します。パスワードがなければ Keep はロックされたままになり、ロックを解除するコマンドが表示されます：chmod -RN ~/Keep。

        ゴミ箱にドラッグするだけだとどうなりますか？

        それも安全です。Amnesia が開いていれば、それに気づいて自分をオフにし、知らせます。開いていなければ、次のログアウト時にログインエージェントが確認し、何も消去せずに自分自身を削除します。

        まだ解決しませんか？

        GitHub で Issue を立ててください。パスワード、ファイルの一覧、そのほか個人的な情報は貼り付けないでください。
