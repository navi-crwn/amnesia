Amnesia for Windows is here. Amnesia untuk Windows sudah hadir.

Same idea as on Mac: your PC forgets everything when you sign out, except the logins and files you keep. Free, open source, and built in public. Idenya sama seperti di Mac: PC kamu lupa segalanya saat kamu sign out, kecuali login dan file yang kamu simpan. Gratis, open source, dan dikembangkan secara terbuka.

Works nowSudah jalan

  • Real cleanup: once you turn it on, your user folder is wiped at sign out, restart and shutdown, and checked again at sign in.Pembersihan sungguhan: setelah diaktifkan, folder user kamu dibersihkan saat sign out, restart dan shutdown, lalu dicek lagi saat sign in.
  • Windows traces go too: recent files, Run box and Explorer history, searches, thumbnails, Notepad tabs, Paint history, clipboard history, Recycle Bin and more.Jejak Windows ikut hilang: file terakhir, riwayat Run dan Explorer, pencarian, thumbnail, tab Notepad, riwayat Paint, riwayat clipboard, Recycle Bin dan lainnya.
  • Profile Vault: an encrypted copy of your logins (Chrome, Edge, Claude, Discord, VS Code and more), saved after you close each app and restored with your password.Profile Vault: salinan login kamu yang terenkripsi (Chrome, Edge, Claude, Discord, VS Code dan lainnya), disimpan setelah kamu menutup app-nya dan dipulihkan dengan password.
  • Your Keep folder and Keep List always stay. Pick what stays right in the app.Folder Keep dan Keep List selalu aman. Pilih apa yang tetap ada langsung dari app.
  • Backups to a USB drive, a cloud folder or your own server, plus moving to a new PC.Backup ke flashdisk, folder cloud atau server sendiri, plus pindah ke PC baru.
  • Quick exits: panic hotkey, USB key, sign out when idle, panic word and Doomsday.Keluar cepat: hotkey panik, kunci USB, sign out saat idle, panic word dan Doomsday.
  • Removes apps installed after you turned it on, and finds leftovers.Menghapus app yang dipasang setelah Amnesia diaktifkan, dan mencari sisa-sisanya.
  • Setup.exe with updates from inside the app, a tray app that looks like the Mac one, light and dark, English and Indonesian.Setup.exe dengan update dari dalam app, app tray yang tampilannya mirip versi Mac, terang dan gelap, bahasa Inggris dan Indonesia.

How to installCara pasang

  1. Open the newest "Amnesia for Windows" release on GitHub.Buka release "Amnesia for Windows" terbaru di GitHub.
  2. Download Amnesia-Setup-…-x64.exe for a normal PC, or -arm64.exe for Windows on ARM (like a Windows VM on a Mac). You can check it against SHA256SUMS.txt.Download Amnesia-Setup-…-x64.exe untuk PC biasa, atau -arm64.exe untuk Windows ARM (misalnya VM Windows di Mac). Bisa dicek dengan SHA256SUMS.txt.
  3. Open it. Windows will warn because the app isn't signed yet: More info → Run anyway. It installs just for you, no admin needed, and stays Off until you turn it on.Buka file-nya. Windows akan memberi peringatan karena app-nya belum bertanda tangan: More info → Run anyway. Terpasang khusus untuk kamu, tanpa admin, dan tetap Off sampai kamu nyalakan.
  4. Later updates come from inside the app: Settings → Update → Check now. Turn Amnesia off before you install one.Update berikutnya dari dalam app: Pengaturan → Update → Cek sekarang. Matikan Amnesia dulu sebelum memasang update.

Windows 10 or 11. Amnesia really deletes once you turn it on, so put what you need in Keep first and check What gets wiped before your first sign out. Found a bug or want something changed? Open an issue (no passwords or private file lists, please).Windows 10 atau 11. Amnesia benar-benar menghapus setelah diaktifkan, jadi simpan dulu yang kamu perlu di Keep dan cek Yang akan dihapus sebelum sign out pertama. Ketemu bug atau mau ada yang diubah? Buka issue (tanpa password atau daftar file pribadi ya).
