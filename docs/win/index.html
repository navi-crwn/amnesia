Amnesia for Windows is on its way. Amnesia untuk Windows sedang dalam perjalanan.

Same idea as on Mac: your PC forgets everything when you sign out, except the logins and files you keep. It's being built right now, in the open. Idenya sama seperti di Mac: PC kamu lupa segalanya saat kamu sign out, kecuali login dan file yang kamu simpan. Sekarang lagi dibuat, terbuka untuk semua orang.

Star the repo to follow alongKasih star untuk ikut memantau Got a Mac? It's ready therePakai Mac? Di sana sudah siap

Works nowSudah jalan

  • Preview: see exactly what would be wiped from your user folder. Nothing gets deleted.Simulasi: lihat apa saja yang akan dihapus dari folder user kamu. Tidak ada yang dihapus.
  • Your Keep folder, the Keep List and what Windows needs to sign you in always stay.Folder Keep, Keep List dan semua yang dibutuhkan Windows untuk login selalu aman.
  • Tray app next to the clock, light and dark, English and Indonesian.App di tray dekat jam, terang dan gelap, bahasa Inggris dan Indonesia.
  • Built and tested on Windows automatically after every change.Otomatis di-build dan dites di Windows setiap ada perubahan.

Curious? Try the previewPenasaran? Coba preview-nya

  1. Sign in to GitHub (downloads from Actions need an account).Login ke GitHub (download dari Actions butuh akun).
  2. Open the latest Windows build with a green check.Buka build Windows terbaru yang centang hijau.
  3. Under Artifacts, download Amnesia-windows-x64 for a normal PC, or Amnesia-windows-arm64 for Windows on ARM (like a Windows VM on a Mac).Di bagian Artifacts, download Amnesia-windows-x64 untuk PC biasa, atau Amnesia-windows-arm64 untuk Windows ARM (misalnya VM Windows di Mac).
  4. Unzip and open Amnesia.exe. Windows will warn because the app isn't signed yet: More info → Run anyway.Unzip lalu buka Amnesia.exe. Windows akan memberi peringatan karena app-nya belum bertanda tangan: More info → Run anyway.

Windows 10 or 11. The preview only shows a list and never deletes anything.Windows 10 atau 11. Preview ini cuma menampilkan daftar dan tidak pernah menghapus apa pun.
