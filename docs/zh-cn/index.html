02 · 你的 Mac，每一天

这些东西，每天都有？

你的 Mac 每天都在悄悄记录你做过的事。浏览器保存着你的浏览记录和 Cookie。下载、桌面和文稿里堆满了只用过一次的文件。App 会写入缓存和日志，终端会记住你输入过的每一条命令。

日积月累，直到你手动清理，或者永远不清理。

03 · 退出登录

退出登录，全部忘掉。

按下“Log Out”、重启或关机，Amnesia 就会把这些全部清除。只有你选中的会留下：你的 Keep 文件夹、Keep List 里的 App，以及 Profile Vault 里的登录状态。已安装的 App 也会保留。

下次登录时它会再检查一遍，所以即使死机或断电，也不会留下痕迹。

Selective Amnesia 就是这个意思：除了你选择保留的，一切都会被忘掉。

    04 · 保留什么

    清除什么，保留什么。

    在你按下“Turn On”之前，什么都不会删除，而且你随时可以先查看列表。可以搜索，也可以把最大的文件排在最前面。

    退出登录时清除

    • 浏览记录和 Cookie
    • Desktop, Downloads, Documents, Pictures, Movies, Music
    • 缓存、日志、终端历史记录
    • 废纸篓里的所有内容
    • 不在保险库里、也不在 Keep List 上的 App 数据

    安全保留

    • Keep 文件夹里的所有内容（位置、名称随你定）
    • 保存在 Profile Vault 里的登录状态（用 Restore 恢复）
    • Keep List 上的 App（VPN、SSH 密钥、Apple 账户…）
    • 虚拟机（UTM、Parallels、VirtualBox、VMware Fusion），默认保留
    • 已安装的 App 本身

    05 · Profile Vault

    一个密码，找回所有登录。

    一个存放 App 登录状态的加密保险箱。有了它，你登录一台干净的 Mac 后，一步就能让 Chrome、WhatsApp、Claude 和你的编程工具恢复就绪。

    • AES-256. 用 7-Zip 加密。忘了密码，谁都打不开。
    • 轻量快照。 浏览器保存时不含缓存：大约 1 GB 变成 150 MB。
    • Save & Log Out。 一键保存你的登录状态，然后退出登录。如果保存失败，就会取消退出登录。
    • Undo Restore。 Mac 上的数据比快照更新？会先问你。Keep List 上的内容永远不会被覆盖，而且在你下次退出登录之前，只要一个按钮就能把原来的数据放回去。

    Memory Recall 干净地退出登录后，Restore Profiles 会找回所有登录状态。

    Global Amnesia 输错 3 次密码或输入紧急口令，保险库就会被永久删除。

    06 · 每一天

    用 Amnesia 的普通一天。

    设置好之后，你只需要做这些。

    1. 01

      登录

      你的 Mac 从干净状态开始。打开 Profile Vault，输入密码，按“Restore Profiles”。

    2. 02

      工作

      所有登录状态都回来了。明天还要用的文件，放进 Keep 文件夹。

    3. 03

      Save & Log Out

      你的登录状态存回保险库，然后退出登录。

    4. 04

      已忘记

      其他一切都被清除，不留痕迹。

    Pause 1 Session 跳过下一次退出登录和登录的清理，不用关闭 Amnesia。

    07 · Backup

    随处备份。

    Keep 文件夹、选定文件夹和 Profile Vault 的加密 .7z 副本（AES-256，文件名也加密）。

    • U 盘、通过 SSH 连接的自己的服务器、Google Drive、Dropbox、OneDrive、Box 或 pCloud。每天或每周一次，你还可以检查备份文件。
    • 每次备份都是一个带日期的新文件。Amnesia 从不删除旧备份。

    Memory Recall Restore Files 会把文件放回原来的位置。Get Vault from Backup 能找回丢失的保险库。

    08 · 隐私

    什么都不会离开你的 Mac。

    Amnesia 没有服务器、没有账户、没有跟踪、也没有统计分析。一切都在你的 Mac 上运行。

    没有服务器 没有账户 没有跟踪 AES-256 从不使用 sudo 历史记录不含文件名 紧急口令

    懂的都懂 😉

    给那些不想解释的人。

    要把 Mac 借给别人？

    退出登录，再登录，然后交给对方。浏览记录、登录状态、最近的文件和聊天记录都已经没了。你的保险库保持锁定。

    家人太好奇？

    你的浏览记录撑不过一次退出登录。没人需要知道你凌晨三点的那次疯狂购物。

    “就打开看一下嘛。”

    登录后只看到一个空空的桌面。还被要求输入保险库密码？改输你的紧急口令。保险库就没了，如果你设置过，Keep 文件夹也会一起没了。没有任何戏剧性。

    丢了或被偷了？

    退出登录后，你的浏览记录、登录状态和聊天记录都已经没了，保险库也是 AES-256 加密的。再打开 FileVault，让 Keep 文件夹在磁盘上也是加密的。

    $ amnesia --forget-everything # 一语双关

    老实说明：Amnesia 是在退出登录之后保护你。登录期间，你的 Mac 和平时一样是敞开的，所以记得锁屏。另外，紧急口令一旦使用就无法撤销。

    每天都干净，什么都不丢。

    Amnesia 能做的一切，一目了然。往下滚动，一个按钮一个按钮地拆解这个 App，然后跟着教程走。

    自动清除

    在退出登录、重启和关机时运行，登录时再检查一遍。

    Profile Vault

    Chrome、WhatsApp、Claude 和你的编程工具，用 AES-256 锁起来。一个密码就能全部找回。

    轻量浏览器快照

    Chrome、Brave、Edge、Arc、Vivaldi 和 Opera 可以不含缓存保存：大约 1 GB 变成 150 MB。每个浏览器一个开关。

    Save & Log Out

    一键保存你的登录状态，然后退出登录。如果保存失败，就会取消退出登录。

    自动快照

    忘了按 Save & Log Out？普通退出登录也会先保存有变化的 App。

    选择保留什么

    Keep 文件夹放你的文件，Keep List 放 VPN、SSH 密钥这类 App 数据。虚拟机默认就在列表上。

    先看清楚

    在删除任何东西之前，“What Gets Deleted”会列出所有内容，可以搜索，也可以按“Biggest first”排序。1 GB 及以上的文件会有警告。退出登录时还可以等你确认。

    Pause 1 Session

    跳过下一次退出登录和登录的清理，不用关闭 Amnesia。

    随处备份

    U 盘、通过 SSH 连接的自己的服务器、Google Drive、Dropbox、OneDrive、Box 或 pCloud。每天或每周一次，你还可以检查备份文件。

    历史记录

    Mac 什么时候被清理、保存了哪些 App、备份什么时候运行。从不记录文件名。

    紧急口令

    输入它，或者密码输错 3 次，保险库就会被永久删除。

    迁移到新 Mac

    把保险库和钥匙串密钥一起带走，这样你的 App 在新 Mac 上打开时就是已登录状态。

    开发者工具

    保留你的 SSH、GitHub CLI、shell、编辑器、Docker、云服务和 AI CLI 设置。Pick Apps 只显示你 Mac 上有的那些。

    快速找到任何设置

    在“设置”顶部的搜索框里输入，支持英文或印尼语。窗口大小也可以调整。

    Keep 锁

    在你于 Amnesia 中输入 Keep 密码之前，访达和其他 App 都打不开你的 Keep 文件夹。它会自动重新上锁。它用的是 macOS 权限，而不是加密，所以 Keep 里第一层的文件名仍然可见。

    健康检查

    一个页面告诉你哪里需要你处理：完全磁盘访问权限、iCloud 桌面与文稿、符号链接文件夹、虚拟机、大文件、上次备份和 FileVault。大多数条目都有修复按钮。

    Brankas （实验性）

    放在 Keep 文件夹里的加密磁盘（AES-256），用来存放必须保密的文件。Amnesia 每次清理前都会关闭它，关不上时会告诉你。忘了它的密码，文件就没了。

    签名更新

    只有当版本的 SHA256SUMS.txt 带有有效签名时，App 内更新才会安装。如果没有，就会把你带到发布页面。

    和 iCloud 安全共存

    开启 iCloud 桌面与文稿时，这两个文件夹会被跳过，所以不会从 iCloud 或你的其他设备上删除任何东西。符号链接文件夹永远不会通过链接被清空。

    Claude 和 Claude Code

    把 Claude 加到 Keep List，你的 Claude Code 聊天记录（~/.claude）也会保留。退出登录前，保险库里勾选的 App 会生成新快照，所以恢复时永远不会是旧数据。

      01 / 10

      打开 Amnesia，阅读警告

      Amnesia 第一次打开时会开始一个简短的引导。选择你的语言，阅读 Amnesia 会删除什么，然后勾选表示你已了解。此时还不会删除任何东西。

      • 之后可以在“设置”里重新打开这个引导。

      02 / 10

      快速检查

      Amnesia 会检查它需要的东西：它的引擎、7-Zip、Apple 命令行工具和完全磁盘访问权限。没有变绿的项目旁边都有一个按钮。

      • 完全磁盘访问权限：系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 打开 Amnesia 的开关，然后点“Quit & Reopen”。
      • 之后，设置 → 健康检查会显示同样的内容，还有更多，比如 iCloud 桌面与文稿和你的上次备份。
      • 有了它，清理才能处理桌面、文稿和下载文件夹。

      03 / 10

      选择保留什么

      选择你的 Keep 文件夹（默认是 ~/Keep），并打开那些数据永远不该被清除的 App。VPN App 会被推荐，你的 Apple 账户已经帮你勾上了。

      • 之后可以在 Keep List 页面修改。
      • 在这台 Mac 上写代码？Keep List → Pick Apps → Developer tools & terminal 会保留你的 SSH、Git 和 CLI 设置。
      • 用 Claude？Pick Apps → Claude → Save 也会保留 Claude Code 聊天记录。

      04 / 10

      创建 Profile Vault

      打开 Profile Vault，输入一个至少 12 个字符的密码，输两次。紧急口令是可选的。

      • 把密码记在一个安全的地方。没有人能帮你找回它。
      • Global Amnesia 输入紧急口令会永久删除保险库。

      05 / 10

      选择 App，做第一个快照

      点选要保存的 App，为每个浏览器选择 Light 或 Full，像平时一样登录这些 App，然后按“Snapshot Now”。

      • Snapshot Now 不需要密码。
      • Light 会跳过缓存：大约 1 GB 变成 150 MB。

      06 / 10

      备份，连同保险库

      选择备份位置，保持勾选“Include Profile Vault”，然后按“Back Up Now”。再用“Check a Backup File”确认里面的保险库能打开。

      • Memory Recall 万一保险库丢了，Get Vault from Backup 可以把它找回来。
      • 每次备份都是一个带日期的新文件。旧备份永远不会被删除。

      07 / 10

      看一眼列表

      What Gets Deleted 会显示下次退出登录会删除的所有内容，按类别分组。还有需要的东西？把它移到 Keep 文件夹，或者把 App 加到 Keep List。

      • 打开这个列表不会删除任何东西。
      • 勾选“Biggest first”，并留意关于 1 GB 及以上文件的橙色警告。
      • 开启“Remove apps installed later”后，这些 App 也会出现在这里的“Apps installed later”分组中。

      08 / 10

      Turn On

      在主页卡片上按“Turn On Amnesia”，阅读弹窗。在你退出登录之前，这次会话都是安全的。

      • Selective Amnesia 从现在起，每次退出登录、重启和关机，除了你选择保留的，其他一切都会被忘掉。

      09 / 10

      每一天：Save & Log Out，然后 Restore

      今天的工作做完了？在菜单栏按“Save & Log Out”。重新登录后，打开 Profile Vault，输入密码，按“Restore Profiles”。

      • Memory Recall Chrome、Claude、WhatsApp 等 App 都会恢复成已登录状态。
      • 用 Light 保存的？在浏览器的扩展页面上按“Repair”。

      10 / 10

      更新 Amnesia

      务必按这个顺序：Turn Off，安装更新（.dmg 或 brew upgrade），打开 Amnesia，Turn On。

      • 在 Amnesia 开启时安装，可能会被当成一次退出登录，从而清除当前会话。
      • 在 App 内更新？它只会安装带有效签名的版本。

        第 8 步之前不会删除任何东西。

        12 · FAQ

        常见问题，一次解答。

        安全

        我的数据会被发送到别处吗？

        不会。Amnesia 没有服务器、没有账户、没有跟踪、也没有统计分析。一切都在你的 Mac 上运行。只有当你设置了服务器或云端备份时，才会有一个加密的 .7z 文件离开你的 Mac，直接发到你选定的位置，没有你的密码谁也读不了。检查更新只会向 GitHub 查询最新版本号，默认每周一次。你可以在“设置”里改成每 2 周、每月，或者关闭。

        有 Windows 版吗？

        有，Amnesia for Windows v0.8.1，正式版。它会在注销、重启和关机时清除数据，并且有保险库、备份、Keep 锁、保险箱、健康检查，以及支持 App 内签名更新的 Setup.exe。请看 Windows 页面。

        能在不删除任何东西的情况下试用吗？

        可以。在你按下“Turn On”之前，Amnesia 一直是关闭的。What Gets Deleted（或 设置 →“See what would be deleted now”）会先显示完整列表。

        被清除的文件去哪了？还能找回来吗？

        退出登录时，它们会被移到 Amnesia 自己的文件夹（~/.amnesia-trash），下次登录后在后台清空。它们不会进 macOS 废纸篓，也无法找回。需要的东西请放进 Keep 文件夹、Keep List 或保险库。

        我的 Keep 文件夹是加密的吗？

        Amnesia 不会加密它。在你输入 Keep 密码之前，Keep 锁会阻止访达和其他 App 打开它，但它用的是 macOS 权限，不是加密。打开 FileVault 让整个磁盘加密，必须保密的文件请放进 Brankas。

        如果 Mac 死机或断电怎么办？

        登录时的检查会兜底：如果上次退出登录没有完成，登录检查会执行完整的清理。

        为什么要完全磁盘访问权限？

        这样 macOS 就不会对每个文件夹（桌面、文稿、下载…）都询问一遍，退出登录时的清除也才能真正处理到它们。你只需要允许一次。

        我在用 iCloud 桌面与文稿，会有问题吗？

        这种情况下 Amnesia 会跳过桌面和文稿，因为清除它们也会从 iCloud 和你的其他设备上删除这些文件。健康检查和 What Gets Deleted 都会提示你。如果你希望清除它们，请先关闭这个 iCloud 选项。

        需要我的 Mac 密码或 sudo 吗？

        不需要。Amnesia 只在你自己的用户账户内运行，从不使用 sudo。只有在你为迁移到新 Mac 而保存钥匙串密钥时，macOS 才会要求输入你的登录密码。

        Backup

        设置备份需要用到终端或 Chrome 吗？

        不需要。对于服务器，输入一次密码，Amnesia 会安装一个 SSH 密钥。对于 Google Drive、Dropbox、OneDrive、Box 或 pCloud，通过浏览器登录即可。

        怎么知道备份真的能用？

        在“备份”页面按“Check a Backup File”，选择那个 .7z。Amnesia 会在一个临时文件夹里打开其中的保险库，显示里面有哪些 App，然后删除临时文件夹。你自己的保险库不会被动到。

        我不在电脑前时，定时备份也会运行吗？

        会，只要 Amnesia 图标在菜单栏里，并且密码保存在钥匙串中。如果是 U 盘，它会等到插上后再备份。每次都会有通知。“Run the scheduled backup now”可以马上测试。

        怎么从备份中找回文件？

        备份 → Restore Files：选择 .7z，勾选文件夹或文件，然后按“Restore to Original Place”。Amnesia 记得每个文件夹原来在哪里（外置硬盘上的也记得）。原位置已有的内容会先移到 ~/.amnesia/before-restore，不会覆盖任何东西。硬盘没插上？用“To Another Folder”。

        为什么双击打不开备份？

        备份用 AES-256 加密，连文件名列表都是加密的。Mac 自带的归档实用工具打不开这种文件。请用 Amnesia 里的 Restore Files、免费 App Keka，或者终端：~/.amnesia/bin/7zz x file.7z（在提示时输入密码，不要把密码写进命令里）。

        Check a Backup File 说备份里没有保险库，是坏了吗？

        没坏。这个备份是在“Include Profile Vault”关闭时（或 v5.13 之前）做的。里面的文件没问题。如果是密码错误，提示信息会单独说明。

        定时备份要我输入 Mac 密码，为什么？

        如果是旧版 Amnesia 把备份密码存进钥匙串的，macOS 会询问一次。按“Always Allow”。从 v5.17 起，Amnesia 会以自己的名义重新保存它，之后就不会再问了。

        旧备份会被删除吗？

        永远不会。每次备份都是一个带日期的新文件。不再需要时，请自己删除旧的。

        Profile Vault

        忘了保险库密码怎么办？

        那就谁都打不开它了，包括你自己。新建一个保险库，然后重新登录你的 App。还记得密码，只是想换一个？用 Profile Vault 页面上的“Password”按钮。

        密码输错 3 次会怎样？

        保险库会被永久删除。最后一次尝试前，Amnesia 会提醒你。如果保险库在某个备份里，可以在 Move to a New Mac → Get Vault from Backup 把它找回来。

        Light 和 Full 有什么区别？

        Light（仅限浏览器）不保存缓存和网上应用店扩展的程序文件，所以 Chrome 会从大约 1 GB 变成 150 MB。登录状态、书签、扩展设置以及通过其他方式安装的扩展始终会保存。用 Light 恢复后，在浏览器的扩展页面上按“Repair”。Full 保存除缓存以外的所有内容。

        Save & Log Out 会覆盖我的旧快照吗？

        只覆盖它保存的那些 App，而且要等新快照成功保存之后。不在列表里的 App 保留原来的快照。如果保存失败，你不会被退出登录。

        自动快照是做什么的？

        当你以正常方式退出登录、重启或关机时，Amnesia 会先保存数据有变化的 App（最多 150 秒），然后再清理。如果你刚用过 Save & Log Out，或者开启了 Pause 1 Session，就会跳过。关闭它后，普通退出登录只清理、不保存。

        我恢复之后，较新的数据被覆盖回旧的了。能撤销吗？

        可以，在你下次退出登录之前都行。在 Profile Vault 页面按“Undo Restore”，恢复前的数据就会回来。从 v5.23 起，当 App 的数据比快照更新时，Amnesia 也会先问你，而且永远不会覆盖 Keep List 上的内容。

        紧急口令是什么？

        一个你自己选的可选词。在密码框里输入它，会立刻删除保险库（如果你设置过，还会清空 Keep 文件夹）。

        日常使用

        明天还需要这些文件，怎么办？

        退出登录前把它们移到 Keep 文件夹。或者，如果只是一天，就按“Pause 1 Session”：下一次退出登录和登录都不会清除。

        能取消退出登录吗？

        可以，只要在“设置”里开启“Check before logout”：退出登录、重启和关机都会停在 What Gets Deleted 页面，直到你按“Continue”或“Cancel”。

        登录时主窗口会打开，为什么？

        旧版本会被 macOS 的“再次登录时重新打开窗口”重新打开。从 v5.15 起，Amnesia 登录时只显示菜单栏图标。

        我在用虚拟机，会被清除吗？

        默认不会。Amnesia 发现 UTM、Parallels、VirtualBox 或 VMware Fusion 的数据时，会把它加到 Keep List 一次。你关掉后它就保持关闭，那一行会注明它会在退出登录时被清除。What Gets Deleted 也会对 1 GB 及以上的文件发出警告。

        废纸篓也会被清空吗？

        会，每次退出登录都会。What Gets Deleted 会把它单独显示成一组“Trash (emptied at logout)”，并标出大小。还需要的东西请先拿出来。

        怎么更新？

        按“Turn Off”，安装新版本（.dmg 或 brew upgrade），打开 Amnesia，按“Turn On”。

        App 内更新安全吗？

        只有当版本的 SHA256SUMS.txt 带有 Amnesia 内置开发者密钥的有效签名时，才会安装。如果签名缺失或不对，它会打开发布页面，什么也不安装。

        能迁移到新 Mac 吗？

        可以，Move to a New Mac 页面会一步步带你完成。Prepare Move 把你的钥匙串密钥存进保险库，用一个备份把它带过去，然后 Restore Keys 在新 Mac 上把它们放回去。

        Uninstall

        怎么卸载？

        打开“设置”，按“Uninstall Amnesia”。它会永久关闭 Amnesia，并把 App 移到废纸篓。勾选一个复选框还可以同时删除保险库、快照、Keep List 和设置（同样移到废纸篓）。你的 Keep 文件夹永远不会被动到。更喜欢用终端？bash ~/.amnesia/uninstall.sh（加上 --all 会把保险库也删掉）。用 Homebrew：brew uninstall amnesia。

        Keep 锁开着，卸载时会怎样？

        Amnesia 会要求输入 Keep 密码，并先解锁 Keep。没有密码的话 Keep 会保持锁定，你会得到一条打开它的命令：chmod -RN ~/Keep。

        如果我直接把它拖进废纸篓呢？

        这样也是安全的。如果 Amnesia 正开着，它会察觉到，自行关闭并告诉你。如果没开着，登录代理会在下次退出登录时检查，不清除任何东西，并把自己删掉。

        还是没解决？

        在 GitHub 上提交 issue。请不要贴出密码、文件列表或任何隐私内容。
