02 · 你的电脑，每一天

这些东西，每天都有？

浏览器保存着你的浏览记录和 Cookie。下载和桌面堆满了只用过一次的文件。Windows 还会记它自己的笔记：最近使用的文件、你在“运行”和文件资源管理器里输入过的内容、搜索记录、缩略图、记事本标签页、剪贴板历史记录。

越积越多，直到你手动清理，或者永远不清理。

03 · Sign out

注销，全部忘掉。

注销、重启或关机，Amnesia 就会把这些全部清除。Windows 一问“可以注销吗？”，Amnesia 就开始清理，Windows 会一直显示“Amnesia is cleaning up...”直到完成。只有你选中的会留下：你的 Keep 文件夹、你的 Keep List，以及保险库里的登录状态。已安装的程序也会保留。

下次登录时它会再检查一遍，所以死机或断电也不会留下痕迹。

Selective Amnesia 就是这个意思：除了你选择保留的，一切都会被忘掉。

    04 · 保留什么

    清除什么，保留什么。

    安装后，Amnesia 处于关闭状态。在你勾选“I understand”并按下“Turn On”之前，什么都不会删除，而且你可以先查看列表。

    注销时清除

    • 浏览记录、Cookie 和登录状态（Chrome、Edge 等）
    • Desktop, Downloads, Documents, Pictures, Videos, Music
    • Windows 痕迹：最近使用的文件、“运行”和文件资源管理器的历史记录、搜索记录、缩略图、记事本标签页、剪贴板历史记录、回收站
    • 不在保险库里、也不在 Keep List 上的 App 数据

    安全保留

    • Keep 文件夹里的所有内容（它有紫色图标、桌面快捷方式，并在文件资源管理器的侧边栏里有个位置）
    • Keep List 上的文件夹，比如 .ssh 或你的代码编辑器设置
    • 保存在保险库里的登录状态（用 Restore 和你的密码恢复）
    • 云盘文件夹：OneDrive、Dropbox、Google Drive、iCloud Drive、Nextcloud、MEGA、Box、pCloud、Proton Drive，以及 Windows 识别为同步文件夹的其他所有文件夹
    • 虚拟机（VirtualBox、Hyper-V、VMware、WSL、Docker、Android 模拟器）以及 1 GB 及以上的光盘映像
    • Microsoft Store App 数据和 App 保存的密码，除非你在“设置”里打开相应开关
    • 已安装的程序、其他磁盘，以及 Windows 让你登录所需的内容

    05 · 为真实的电脑而做

    该清的清掉，不该清的留着。

    0.8 版来自一次完整审查，并在一台真实的 Windows 11 笔记本上做过测试。下面是它每次注销时遵循的规则。

    • Windows 一问就开始清理。 所以一次普通注销在登录界面出现之前就已经清理干净了。Windows 仍占用着的文件会在下次登录时处理，保险箱会在清理完成后关闭。
    • 云盘文件夹会保留。 把它们移走，在同步 App 看来就像是“删除”，它可能会连云端的文件也一起删掉。只存在于云端的文件同样不会动。
    • 虚拟机会保留。 虚拟机磁盘和 1 GB 及以上的光盘映像会被保留。你可以在“设置”的 Protection 中关闭这一项。
    • 新 App 先等 3 天。 开启“Remove new apps”后，新 App 的文件夹会先进 Amnesia 的回收区，绝不会直接消失。按“Keep”，它的程序和数据文件夹就会加入你的 Keep List。

    坦白说的取舍：因为清理在 Windows 询问时就开始了，过了这个时间点再取消注销，也不会把任何东西找回来。这就相当于按了“Clean now”。

    06 · Profile Vault

    一个密码，找回你的登录。

    一个存放 App 登录状态的加密保险箱：Chrome、Edge、Brave、Firefox、Discord、Telegram、WhatsApp、Slack、Session、Element、Obsidian、Thunderbird、Bitwarden、VS Code、Claude、Antigravity、Windsurf、Gemini CLI、OpenCode、Git，以及你添加的任何文件夹。登录一台干净的电脑，输入一个密码，它们就都回来了。

    • AES-256. 每个快照都有自己的随机密钥，并用保险库的密钥锁住。忘了密码，谁都打不开。
    • 每个 App 关闭后就会保存。 在后台进行，而且只在有变化时才保存。注销时只负责清理，所以很快。
    • 一个备用快照。 每个 App 都会保留最新快照的上一个版本，以防最新的那个看起来不对。
    • 能找到你的 App。 它会推荐它还不认识的已安装 App，并用一个强度条显示你的密码有多难猜。

    Memory Recall Restore 用你的密码找回你的登录状态。登录后会有通知提醒你。

    Global Amnesia 输错 3 次密码或输入紧急口令，保险库就会被永久删除。

    坦白说明：Windows 会把保存的登录状态绑定到你的 Windows 用户上。快照只能在这台电脑、这个用户上恢复，换一台电脑不行。

    07 · 每一天

    用 Amnesia 的普通一天。

    设置好之后，你只需要做这些。

    1. 01

      Sign in

      你的电脑从干净状态开始。点击提醒，输入保险库密码，按“Restore”。

    2. 02

      工作

      你的登录状态都回来了。明天还要用的文件，放进 Keep 文件夹。

    3. 03

      关闭你的 App

      每个保险库里的 App 在你关闭它之后会单独保存。

    4. 04

      注销

      其他一切都被清除，不留痕迹。

    暂停一次会话 跳过下一次注销和登录的清理，不用关闭 Amnesia。

    08 · Backup

    备份，还有新电脑。

    你的 Keep 文件夹、Keep List 和保险库放进一个加密文件。它用你的保险库加密，所以不需要额外的密码。

    • 备份到 U 盘、另一块磁盘、云盘文件夹（OneDrive、Google Drive 桌面版）或者通过 SSH 连接的自己的服务器。每天或每周一次。
    • 每次备份都是一个带日期的新文件。Amnesia 从不删除旧备份。
    • 正在使用中的文件会在结果里列出，这样你就知道哪些需要再备份一次。如果恢复过程被断电打断，它会自己清理现场，并把你原来的保险库放回去。

    Memory Recall 迁移到新电脑：安装 Amnesia，选择一个备份，输入你的保险库密码。你的 Keep 文件夹、Keep List 和保险库就都回来了。

    09 · 快速撤离

    要走了？它来收拾。

    应对好奇的人、借来的电脑，或者有人逼你“就打开看一下”。这些功能默认都是关闭的，需要你在“设置”里打开。

    紧急快捷键

    按 Ctrl + Alt + Shift + X（或 Q、或 F12）。屏幕立刻锁定，Amnesia 清理并注销，不会等其他 App。暂停时也有效，Windows 反应慢时还会再试一次。

    CtrlAltShiftX

    USB 钥匙

    选一个 U 盘。拔掉它，Amnesia 就会清理并注销，或者清理并关机。由你决定。

    闲置时注销

    人走开了？5 到 60 分钟后会出现 60 秒倒计时，然后锁定、清理并注销。动一下鼠标就能停止。

    紧急口令

    被要求输入保险库密码？改输你的紧急口令。保险库会当场删除，如果你设置过，Keep 文件夹也会一起删除。

    Doomsday

    连续输错 3 次保险库密码，保险库就会被永久删除。最后一次尝试前 Amnesia 会提醒你。这项可以关闭。

    老实说明：Amnesia 是在注销之后保护你。登录期间，你的电脑和平时一样是敞开的，所以请锁屏（Win+L）。快速撤离不会等你保存未保存的工作，紧急口令一旦使用也无法撤销。

    10 · 锁

    把它锁好，实话实说。

    “设置”的 Advanced 里有两把锁，Keep List 页面里还有一个保险箱。下面说清楚它们能做什么、不能做什么。

    Keep 锁

    你的 Keep 文件夹只能通过 Amnesia 用它自己的密码打开：Open Keep、托盘菜单或桌面快捷方式。当你锁屏（Win+L）时、在你设定的分钟数之后、以及注销和登录时，它都会重新上锁。锁定期间，任何程序都无法打开或写入其中的文件。

    • 文件本身没有加密。要加密请用 BitLocker。
    • 锁定时文件名仍然可见。
    • 以你的身份登录、又懂 Windows 的人，可以在文件夹的“属性”里解除这个锁。

    机房锁

    适用于多人共用的电脑，比如机房或图书馆。由管理员设置一个 6 位或更多位的 PIN。从此以后，这个 Windows 用户就无法关闭、暂停、退出或卸载 Amnesia，也无法修改它的设置和 Keep List。Amnesia 会在每次登录时启动，输入 PIN 可以打开设置 10 分钟。

    • 仍然有人可以在任务管理器里结束 Amnesia。不过下次登录时的检查照样会清理。
    • 请先设置好你的设置和 Keep List。它们会按当前状态被锁定。

    保险箱 实验性

    Keep 里的一个加密文件夹，用来放你最私密的文件，有自己的密码。关闭时，它是一个加密文件（AES-256-GCM，和保险库同一种格式）。打开时，它是 Keep\Safe。Amnesia 会在每次注销清理之后重新关闭它。

    • 尽量放小一点：每次关闭都要重新打包全部内容，这需要时间。
    • 忘了它的密码，谁都打不开，包括你自己。
    • 如果里面还有文件，卸载时会提醒你。

    11 · 健康检查

    它在正常工作吗？看一眼就知道。

    一个页面回答“Amnesia 现在能正常干活吗？”。绿色表示没问题，黄色和红色告诉你该看哪里，每一行都会说明去哪里修复。

    • 它检查什么。 是否开启、是否随 Windows 启动、上次清理、留到下次登录处理的文件、Windows 安全中心的拦截、云盘文件夹、虚拟机、Keep 锁、保险库、上次备份、紧急快捷键、更新、磁盘剩余空间、内存和电池。
    • 启动项被关了？ 如果有人在任务管理器里关掉了 Amnesia，主页会显示警告，并附带一个“Switch it back on”按钮。
    • 签名更新。 只有当 SHA256SUMS.txt 上的开发者签名验证通过时，更新才会安装。没有签名的话，Amnesia 会打开发布页面，而不是安装任何东西。

    Amnesia 做不到的事，App 里自己就写着

    • 清除是删除文件，并不会覆写磁盘。请开启设备加密。
    • Windows 会在你的用户文件夹之外留下少量痕迹。
    • 保险库和备份的强度取决于你的密码。
    • 目前还没有付费的代码签名证书，所以 SmartScreen 可能会发出警告。

    12 · 会清除什么

    先看，再决定。

    “What gets wiped”是对你下次注销的一次演练。它会列出所有将被清除的文件、文件夹和痕迹。打开它不会删除任何东西。

    • 搜索。 输入名称或路径，比如“Downloads”或“.pdf”。
    • 单个文件夹。 选一个文件夹，看看里面有多少项、有多大。
    • 最大的排前面。 看看什么最占空间。

    Review & sign out 会在你注销前显示同样的列表，加上将被移除的程序，还有一个按钮让你先保留某些东西。

    13 · 隐私

    什么都不会离开你的电脑。

    Amnesia 没有服务器、没有账户、没有跟踪、也没有统计分析。检查更新只会向 GitHub 查询最新版本号。

    没有服务器 没有账户 没有跟踪 AES-256 安装无需管理员权限 没有隐藏的 PowerShell 紧急口令

    想要的话，还有更多。

    下面这些都在“设置”里。额外功能默认关闭，需要你自己打开。

    让 Windows 别再记

    Windows 自带的隐私开关，只针对你：没有最近使用列表、没有剪贴板历史记录、“开始”菜单里没有网页结果、没有广告 ID，Recall 和 Copilot 关闭。“Undo all”会原样恢复之前的设置。

    移除新 App

    在 Turn On 之后只为你安装的程序会在注销时被移除，Microsoft Store App 也一样。它们的文件夹会先在 Amnesia 的回收区等 3 天。按“Keep”，这个 App 的程序和数据文件夹就会加入你的 Keep List。

    保留一个 App

    从列表里选一个已安装的 App，Amnesia 会保留它存放数据的所有文件夹，包括登录状态和设置。

    Store 数据和保存的密码

    两个额外开关：同时清除 Microsoft Store App 数据，以及同时清除 App 保存在凭据管理器里的密码。绝不会动你的 Microsoft 账户、OneDrive 或 Office。

    查找残留

    已卸载程序留下的文件夹和注册表设置。在你勾选之前，什么都不会删。

    一次性 Windows

    为可疑的文件或网站打开 Windows 沙盒。关掉就没了。需要 Windows 专业版或企业版。

    Windows 防护

    针对整台电脑（需要管理员权限，只问一次）：关机时清空页面文件、关闭休眠、关闭 Recall 和活动历史记录。

    签名更新

    检查更新会读取版本上的开发者签名。没有有效签名就不安装：它会改为打开发布页面。

    额外清理列表

    社区列表 Winapp2（约 4,000 个 App），在你按下按钮时从 GitHub 下载。保存的密码永远不会被动到。

    对杀毒软件友好

    清理在 Amnesia.exe 内部运行。如果 Windows 安全中心拦截了什么，主页会告诉你如何允许 Amnesia。绝不会让你“关掉杀毒软件”。

    历史记录

    电脑什么时候被清理、保存了哪些 App、备份什么时候运行。从不记录文件名。

    收集日志

    有什么不正常？在你的 Keep 文件夹里生成一个文本文件，不含文件名。不会发送任何东西。分享什么由你决定。

    磁盘加密检查

    “设置”会显示 BitLocker 或设备加密是否开启，以及如何开启。

    擦除可用空间

    运行 Windows 自带的 cipher /w，让已删除的文件更难被恢复。速度慢，而且会先问你。

    维护。先看清单，再腾空间。

    Amnesia 每次注销时本来就会清空你用户文件夹的大部分内容，所以“维护”是为留下来的东西准备的：你的 Keep 文件夹、你保留的 App，以及这次会话里产生的大文件。每个操作都会先扫描并列出清单，有风险的项目不会替你勾选。

    磁盘概览

    看看是什么占了空间：Keep 文件夹、保险库、回收站、Temp、最大的文件夹和文件、旧的下载。只读，这里不会删除任何东西。

    立即清理

    清空 Temp、崩溃转储、App 缓存和 Amnesia 的回收站。Windows 仍在使用的文件会被跳过。Windows 回收站也在清单里，但从不替你勾选。

    卸载 App

    只为你安装的程序会运行它自己的卸载程序。为所有人安装的程序会打开 Windows 设置。剩下的缓存移到回收站，个人数据会保留，除非你勾选。

    项目构建文件夹

    node_modules、target、build、dist，以及 .NET 项目的 bin 和 obj 可以移到回收站。最近 7 天用过的文件夹或被 git 跟踪的文件夹不会被动。

    旧安装包

    旧的 .msi 和 .msix 文件会移到回收站。setup .exe 文件会列出来，但从不替你选中，磁盘映像和虚拟机也一样。

    安全的小保养

    重启资源管理器，或打开“启动应用”和“存储”设置。不需要管理员。

    拿不准就停下

    如果 Keep List 读不出来或不见了，清理就什么都不删，并记在历史记录里。检查拿不准时，项目会被保留。

    每次都记入历史

    每次“维护”都会连同释放的空间记入历史记录。健康检查还会显示磁盘剩余空间、内存和电池。

    模式与配置组。忘掉多少，由你决定。

    为每次注销选一个模式，只恢复你需要的应用，并在不分享文件的情况下向 AI 请教。每项更改都会先显示预览，并在下次注销时生效。

    Retrograde Amnesia

    每次登录都像一个全新的账户。只保留你的 Keep 文件夹和 Amnesia 运行所需的内容。注销时保险库的自动快照会关闭，你仍可以手动恢复快照。

    Selective Amnesia (推荐)

    Keep 文件夹保留，应用登录从保险库恢复。和以前一样。

    Partial Amnesia

    AppData 中的所有内容都会保留，所以应用会保留设置和登录，缓存也一样。你的文件、下载和桌面会被清除。浏览器自己文件夹里的浏览记录和 Cookie 也会保留，因为那个文件夹被保留了。

    Custom Amnesia

    你自己的 Keep List。当你修改某个模式添加的行时会自动选中。模式只改动它自己标记的部分，所以你自己的行始终保留。

    每次切换前都有预览

    查看从现在起会被清除和会被保留的内容，清除更多时会有警告。切换时不会删除任何东西。模式列表缺失或损坏时，绝不会清空你的 Keep List。

    保险库配置组

    只恢复你需要的，例如工作或个人，或者全部。可以重命名、添加和删除配置组。一个浏览器只保存一套登录，所以用第二个浏览器能把个人使用分开。

        17 · FAQ

        常见问题，一次解答。

        安全

        能在不删除任何东西的情况下试用吗？

        可以。安装后，Amnesia 处于关闭状态，不会删除任何东西。打开 What gets wiped，按“Show preview”：它只会列出将被清除的内容。列表看起来没问题时再开启。

        被清除的文件去哪了？还能找回来吗？

        去了一个你找不到的地方。它们不会进回收站，也无法找回。Amnesia 一旦开启就是真删除，所以请先看 What gets wiped，并把需要的东西放进 Keep 或加到 Keep List。

        我的 Keep 文件夹是加密的吗？

        不是。Amnesia 只负责保留它，不负责加密。请开启 BitLocker 或设备加密：设置 → 隐私和安全性 → 设备加密。Amnesia 的“设置”会显示它是否已开启。

        如果电脑死机或断电怎么办？

        下次登录时的检查会兜底，并完成清理。

        如果我取消注销呢？

        Windows 一问“可以注销吗？”，Amnesia 就开始清理。如果你在那之后取消，比如因为某个 App 要求保存，清理其实已经执行了。这就相当于按了“Clean now”。拿不准的时候，请用 Review & sign out。

        OneDrive、Dropbox 或我的虚拟机会被清除吗？

        不会。云盘文件夹（OneDrive、Dropbox、Google Drive、iCloud Drive、Nextcloud、MEGA、Box、pCloud、Proton Drive 以及任何 Windows 同步文件夹）不会被动，因为移动它们可能会连云端的文件也一起删掉。虚拟机磁盘和 1 GB 及以上的光盘映像也会保留，除非你在“设置”的 Protection 中关闭这一项。

        怎么知道它在正常工作？

        在主页上打开健康检查。每一行都是绿色、黄色或红色，并说明去哪里修复。历史记录会显示每次清理，以及清除了多少项。

        我的数据会被发送到别处吗？

        不会。没有服务器、没有账户、没有跟踪。备份只会去你选定的地方。检查更新会向 GitHub 查询最新版本号（默认每周一次），你也可以关闭它。

        Windows 安全中心或杀毒软件拦截了它，怎么办？

        有东西被拒绝时，主页会告诉你。通常是“受控制文件夹的访问”：Windows 安全中心 → 病毒和威胁防护 → 勒索软件防护 → 允许应用通过受控制文件夹访问，然后添加 Amnesia。请不要关闭你的杀毒软件。

        锁和快速撤离

        有人能绕过 Keep 锁吗？

        能，以你的身份登录、又懂 Windows 的人可以在文件夹的“属性”里解除它。文件也没有加密。它能挡住随手翻看和其他程序，挡不住铁了心的人。想要真正的保护，请用 BitLocker。

        我忘了 Keep 锁的密码。

        打开 Keep 文件夹的“属性”→“安全”，删掉“拒绝”那几行。你的文件都还在。

        按下紧急快捷键会发生什么？

        屏幕立刻锁定，Amnesia 清理并注销，不会等其他 App。未保存的工作会丢失。托盘菜单里也有同样的功能：Panic sign out now。

        保险箱是什么？

        Keep 里的一个实验性加密文件夹，用来放你最私密的文件。关闭时，它是一个加密文件（AES-256-GCM，和保险库一样）。打开时，它是 Keep\Safe。Amnesia 会在每次注销清理之后重新关闭它。尽量放小一点：每次关闭都要重新打包全部内容。

        机房锁能被停掉吗？

        有人可以在任务管理器里结束 Amnesia。下次登录时的检查照样会清理。修改设置或关闭它需要管理员的 PIN。

        Profile Vault

        忘了保险库密码怎么办？

        那就谁都打不开它了，包括你自己。新建一个保险库，然后重新登录你的 App。把密码记在一个安全的地方。

        保险库什么时候保存？

        在你关闭一个有变化的 App 之后，在后台保存（每分钟检查一次）。没有窗口的工具，比如 Claude Code 或 Git，在 3 分钟没有变化后保存。如果 Edge 一直在后台运行（“启动增强”），会在它真正关闭后保存。

        我的登录状态在另一台电脑上能用吗？

        通常不行。Windows 会把保存的登录状态绑定到你的 Windows 用户上，所以快照只能在这台电脑、这个用户上恢复。迁移到新电脑会带上你的 Keep 文件夹、Keep List 和保险库，但有些 App 你可能需要重新登录。

        最新的快照看起来不对。

        如果新快照比上一个小很多，保险库会提示你。恢复时勾选“Use the snapshot before the newest one”。

        紧急口令和 Doomsday 是什么？

        紧急口令是一个你自己选的可选词。在密码框里输入它，会删除保险库（如果你设置过，还会删除你的 Keep 文件夹）。Doomsday 会在连续输错 3 次密码后删除保险库。你可以关闭 Doomsday。

        为什么安装时 Windows 会警告我？

        这个 App 还没有签名，所以 Windows 不认识它。按“More info”，然后按“Run anyway”。想确认一下？用同一版本里的 SHA256SUMS.txt 核对这个文件。

        x64 还是 arm64？

        大多数电脑需要 x64。ARM 版 Windows 请选 arm64，比如骁龙笔记本，或者 Mac 上的 Windows 虚拟机。

        需要管理员权限吗？

        不需要。它只为你安装。只有少数几个可选功能会向 Windows 请求一次管理员权限：Windows 防护、删除残留文件夹和机房锁。

        怎么更新？

        设置 → Update → Check now。安装更新前先关闭 Amnesia，装完再打开。只有开发者签名验证通过时，Amnesia 才会安装更新；否则它会打开发布页面。

        怎么卸载？

        设置 → Uninstall Amnesia，或者像其他 App 一样在“应用和功能”里卸载。它会先关闭，所以不会再清除任何东西。你的 Keep 文件夹始终会保留。如果 Keep 已锁定，它会要求输入 Keep 密码；如果保险箱里还有文件，它也会提醒你。要同时删除设置、Keep List 和保险库，请在框里输入 DELETE。

        Microsoft Store App 和新程序会被移除吗？

        只有开启“Remove new apps”时才会。这时，在 Turn On 之后只为你安装的程序会在注销时被移除，它的文件夹会先在 Amnesia 的回收区等 3 天。按“Keep”就能保留它。Store App 会保留自己的数据，除非你打开“Also wipe Store app data”。

        有 Mac 版吗？

        有，而且历史更久。请看 Mac 页面。

        发现 bug？想改点什么？

        在 GitHub 上提交 issue。请不要贴出密码、私人文件列表或任何个人信息。正因如此，Collect log 不包含文件名。
