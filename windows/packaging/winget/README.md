# winget manifests (not in use)

The folder `0.7.0` is a template from Windows v0.7.0. Nothing in this repo reads it: the build, the tests and the release do
not use it, and it was never sent to winget-pkgs.

Its version, download links and the `FILL_IN_FROM_SHA256SUMS` hashes are out of date. Before anyone submits it, copy it to a
folder with the new version, set the version and the links, and put in the hashes from that release's `SHA256SUMS.txt`.
Do not submit it as it is.
